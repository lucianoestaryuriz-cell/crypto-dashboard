
# 🚀 CryptoAnalyzer

[![Version](https://img.shields.io/badge/version-1.0.0-blue)](https://github.com/seuusuario/crypto-dashboard)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

> Dashboard profissional para análise de criptomoedas com indicadores técnicos e sistema de Score

## ✨ Funcionalidades

- 📊 Dados em tempo real (BTC, ETH, SOL, BNB, XRP)
- 📈 Indicadores técnicos (RSI, MACD, MA50, MA200)
- 🎯 Sistema de Score (0-100)
- 💼 Carteira simulada
- 🔔 Alertas personalizados
- 🛒 Integração com exchanges

```bash
# Clone o repositório
